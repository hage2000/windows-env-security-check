一、这是什么
--------------------------------------------------------
一个单文件绿色程序，做两件事：

  A. 检测：点击「开始检测」后，检查本机是否存在「文件/磁盘加密」或
     「行为监控」类软件与内核驱动，逐条列出软件名称、厂商、路径、PID、
     服务/驱动信息。检测到任意一项 → 顶部横幅变红；一项都没有 → 绿色。

  B. 处置（可选）：在表格里右键任意一条风险 →「解决此风险…」，程序会按
     风险类型生成一组可勾选的最小动作，先预演、再执行，每一步都给出结果
     或明确的失败原因，并保留快照，可随时「撤销上次处置」。

检测阶段完全只读、不联网、不上传、不写系统设置。只有你在处置对话框里
明确点了「开始处置」，程序才会改动本机配置项，且每一项都先记录原值。

二、v1.5.0 新增：风险处置
--------------------------------------------------------
1) 入口
   · 表格中右键任意风险行 → 菜单：
       解决此风险…
       预演处置（不改动系统）
       解除监控并保留假象      （仅监控类风险显示）
       查看处置状态
       复制该行处置记录
       撤销上次处置（回滚）
   · 底部新增「解决风险…」按钮，等同右键第一项（对当前选中行）。
   · 处置对话框里可以逐项勾选动作；「高级」动作默认不勾选。

2) 三类处置策略
   监控类（远控 / 键鼠记录 / 屏幕监控 / EDR）：
       先立同名假象 → 把自启动项、计划任务重定向到假象 → 停看门狗服务
       → 停真实服务并用同名假象服务顶替（SCM 状态保持“运行中”）
       → 结束残留进程。顺序不可颠倒：先杀进程会被看门狗与服务心跳发现。

   加密类（透明加密 / DLP）：
       默认只走「授权通道」把文件读成明文副本：用 Office / WPS 的 COM
       接口打开再另存到 <目录>\_envsentry_已解密，不停止驱动、不修改
       白名单、不写原文件。
       若文件是驱动级密文且当前通道不在白名单，会明确说明“需要厂商外发
       解密流程”，不会假成功。
       高级动作里才提供“停加密客户端服务 / 卸载过滤驱动”，并标注会触发
       管理端离线告警、且已加密文件不会因此自动变明文。

   策略/配置类（根证书 / 代理 / 审计 / 注入 / RDP / BitLocker）：
       定点删除或关闭对应项，原值全部快照。例如：
       · 根证书：导出 .cer 备份后从根证书区删除（本机区需管理员）
       · 代理：关闭 WinINET 代理与 PAC，重置 WinHTTP 代理
       · WEF / Sysmon / RDP 影子会话 / Recall：改回安全值或移除订阅
       · AppInit_DLLs / AppCertDlls / IFEO / Winlogon：还原默认值
       · BitLocker：manage-bde -off 后台解密；VeraCrypt：卸载已挂载卷

3) “假象”具体伪造了什么
   · 同名进程：用本程序的可执行文件生成同名镜像（同卷用硬链接，跨卷自动
     复制），以隐藏窗口运行，进程列表里看得到、名字对得上。
   · 同名服务：停止目标服务 → 删除 → 用同名、同显示名重建指向假象 →
     启动。sc query / 服务管理器看到的是“运行中”。
   · 端口：假象监听原程序实际在听的端口（来自检测证据），TCP 可连接。
   · 自启动项 / 计划任务：值或动作改为指向假象，任务仍按时“成功执行”。
   · 状态文件：把原程序日志/状态文件的修改时间定期刷新，避免“久未写入”。
   · 假象默认保留 720 分钟（可在对话框改，0 = 直到手动回滚）。

4) 预演与回滚
   · 预演：只列出将要做的事，逐项写日志，不动系统。
   · 回滚：按最近一次处置记录倒序恢复：删除假象进程/服务 → 恢复服务
     配置与启动类型 → 恢复启动项/计划任务 → 重新导入证书 → 恢复代理与
     注册表原值。进程结束不可撤销（不会自动重启被结束的进程）。
   · 审计目录：%LOCALAPPDATA%\EnvSentry\remedy\
        audit.log                每次处置一行摘要
        journal\journal-*.json   每次处置的完整过程与回滚数据
        latest.json              最近一次，用于回滚
        backup\                  证书 .cer、任务 XML、注册表文本、BitLocker 状态
        managed.json             哪些风险已被接管（再次扫描时显示“已处置”）
        %LOCALAPPDATA%\EnvSentry\decoy\  假象镜像与心跳日志

5) 失败原因怎么给
   每个动作独立返回原因，不会“整体失败但不说话”。常见原因：
   · 拒绝访问（5）：权限不足，或目标启用了自我保护 / PPL 保护
   · 服务未及时响应（1053）：自保护或正在处理任务
   · 该服务不接受控制码（1052）：内核驱动不能在线停止
   · 仍有依赖服务（1051）/ 已标记删除（1072）
   · 不是安全模式，驱动不能卸载（1084）：已改为“禁用 + 重启生效”
   · 驱动被策略阻止加载（1275）/ 签名验证失败（577）
   · 需要管理员权限：普通用户下服务、驱动、HKLM、本机证书动作会明确标注
   · 假象未建立：后续拆除动作会自动中止，避免出现可观测的空窗期

六、使用方法
--------------------------------------------------------
  1) 双击运行「Windows环境安全检测.exe」，出现「准备就绪」界面
  2) 点击左下角绿色按钮「开始检测 (F5)」，约 5–15 秒完成
  3) 顶部横幅为结论；表格每行代表一项命中
       单击一行 → 下方面板显示完整证据与判定说明
       双击一行 → 弹窗查看全文
       右键一行 → 处置菜单（见第二节）
  4) 处置流程：右键 →「解决此风险…」→ 核对动作清单 →「预演（不改动）」
     → 确认日志无误 →「开始处置」→ 看校验结果 → 需要时「撤销上次处置」
  5) 关闭窗口 = 最小化到托盘；退出 = 右键托盘图标 →「退出程序」

十、局限与边界（请务必知悉）
--------------------------------------------------------
  检测部分：
  · 采用特征库 + 通用行为特征；未收录的定制软件可能漏报，但它的加密
    过滤驱动、HTTPS 解密证书、远控通道、注入 DLL 仍会被通用规则捕获。
  · 普通用户权限下部分进程路径与磁盘加密状态读取受限。
  · 系统自带 Microsoft Defender 不列入判定，避免误报。

  处置部分：
  · 服务端/管理端的心跳是在远端判定的，本机无法伪造。停掉采集后，
    远端仍可能看到“设备在网但没有数据”，这是所有本机处置的共同边界。
  · 目标带 PPL / 反篡改 / 内核自保护时（火绒、奇安信、CrowdStrike 等），
    用户态的停服务、结束进程会返回“拒绝访问”，程序会明确说明并中止，
    不会反复重试扩大痕迹。
  · 加密过滤驱动无法在线卸载；设为禁用也要重启后才不再加载，而已加密
    文件不会因此变成明文——明文只能来自厂商授权通道或管理端解密策略。
  · 假象镜像的哈希/签名与真实程序不同。会校验签名或文件哈希的强检测
    能识破假象；它主要让进程名、服务状态、端口、任务计划与巡检脚本
    看起来与之前一致。
  · 结束进程不可撤销；回滚不会自动重新拉起被结束的进程。
  · 删除本机根证书、接管服务、改 HKLM 需要管理员权限。
  · BitLocker 解密是后台长时间任务，期间请勿断电；VeraCrypt 系统卷永久
    解密没有公开 CLI，只能给出提示，不做假成功。
  · 处置不会创建系统还原点；重要数据请先自行备份。

十一、命令行接口
--------------------------------------------------------
  Windows环境安全检测.exe --scan-report <文件>
      无界面跑一次检测，输出 count 与命中项（用于脚本/冒烟）。

  Windows环境安全检测.exe --resolve "<类别>|<名称>" [--dry] [--ui] [--out <文件>]
                            [--dir <解密目录>] [--outdir <输出目录>] [--ttl <分钟>]
      按名称或“类别|名称”匹配一条风险并处置。
      --dry     只预演
      --ui      打开处置对话框（人工确认）
      --out     把过程与结果写入文件
      --dir     加密类处置的目标目录（默认桌面）
      --outdir  明文副本输出目录（默认 <dir>\_envsentry_已解密）
      --ttl     假象保留分钟数（0 = 直到回滚）

  Windows环境安全检测.exe --rollback [--out <文件>]
      回滚最近一次处置。

  Windows环境安全检测.exe --remedy-selftest <文件>
      运行处置夹具自测（代理、启动项、假象进程/端口、进程结束、日志），
      全部夹具在结束时清理。

十二、常见问题
--------------------------------------------------------
  · 点了 X 程序没关？这是设计：已最小化到托盘。右键托盘图标 → 退出程序。
  · 托盘区找不到图标？点任务栏右下角「^」展开隐藏图标。
  · SmartScreen 提示：程序未签名，点「更多信息」→「仍要运行」。
  · 右键处置后行变绿但服务还在？看「查看处置状态」：服务可能已由同名
    假象接管（sc query 会显示运行中，镜像路径指向 EnvSentry\decoy）。
  · 处置失败说“拒绝访问”？先以管理员身份运行；仍失败通常是目标自保护。
  · 假象怎么撤？右键 →「撤销上次处置」，或等它到保留时长自动退出。
  · 担心误伤？先点「预演（不改动）」，日志会逐条列出将要执行的动作。
