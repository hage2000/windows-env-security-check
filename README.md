## 为什么这个工具重要

大多数侵入性软件不会出现在"设置 → 应用"里。

- **透明加密 / DLP 客户端**把你的文件在磁盘上就地加密：在许可环境内正常打开，带回家或发出去就是乱码；它还会把自己注入到你的每一个进程里，读取剪贴板、打印与截图。
- **屏幕与行为监控**按秒级截屏、记录窗口标题、统计停留时长，通常没有托盘图标，任务管理器里也叫不出名字。
- **远程控制**可能正与远端保持一条已建立的连接，对方能看你的屏幕、动你的鼠标。
- **键盘记录器**静默记录每一次击键，密码、聊天、网银全部落盘。
- **HTTPS 中间人证书 + 系统代理**把根证书装进"受信任根证书"区，你的银行页面、邮箱、网页版聊天流量在网关侧全部明文可见。
- **行为审计驱动 / 注入 DLL**（AppInit_DLLs、Winlogon 篡改、IFEO 劫持）让"谁在看着我"根本无法靠肉眼判断。

这些软件的共同特征是：**静默安装、无感运行、无卸载入口、不告知用户**，而它们恰好掌握着你最私密的数据。

**本程序做的事情：把这层看不见的东西一次性、逐条、带证据地摊开在你面前。** 软件名称、厂商、路径、PID、服务与内核驱动、注入到本程序里的第三方 DLL、根证书颁发者、系统代理地址、远控进程的真实外连状态——红/绿结论直接呈现，不需要你懂安全知识。

> 检测阶段完全只读。它不阻断、不查杀、不改任何系统设置——除非你在处置对话框里自己勾选并点了「开始处置」。

### 如何自己证明"它真的没联网"

1. **资源监视器**：`Win+R` → `resmon` → 「网络」标签页 → 看本程序是否有任何 TCP/UDP 端点或收发字节。全程为 0。
2. **防火墙出站规则**：`wf.msc` → 出站规则 → 阻止本程序的一切出站连接 → 再次检测，**结果完全一致**。
3. **物理断网**：拔掉网线 / 关闭 Wi-Fi 后运行，功能不打折扣。
4. **Process Monitor**（Sysinternals）：过滤 `Process Name is WindowsEnvSecurityCheck.exe`（即你的 exe 文件名）+ `Operation is TCP/UDP Send`，命中数为 0。

任意一项验证不成立，请在 [Issues](https://github.com/hage2000/windows-env-security-check/issues) 公开指出——这是可以被证伪的承诺。

## 检测什么

点击「开始检测 (F5)」后约 5–15 秒完成一次全量只读扫描（约 1600–1700 个证据点），命中任意一类即顶部横幅变红，表格逐条列出**软件名称、厂商、路径、PID、服务/驱动信息**；全部未命中则为绿色「未检测到」。

| 类别 | 覆盖内容 |
| --- | --- |
| **透明加密 / DLP 客户端** | 亿赛通、天锐绿盾、迅软 DSE、华途、中孚、IP-guard、天空卫士、明朝万达、天融信、网御、任子行等 |
| **文件系统加密过滤驱动** | 驱动 `Group=FSFilter Encryption` 即视为透明加解密（未收录厂商同样会命中） |
| **磁盘 / 全盘加密** | BitLocker、VeraCrypt、TrueCrypt、BestCrypt、DiskCryptor、企业级 FDE |
| **远程控制 / 屏幕共享** | 向日葵、TeamViewer、AnyDesk、ToDesk、RustDesk、VNC、Radmin、Splashtop、Chrome 远程桌面、快速助手等，并检查是否正与远端保持 `ESTABLISHED` 连接 |
| **键盘记录 / 间谍软件** | Ardamax、Actual Keylogger、超级眼、网眼、域之盾、网路岗、WorkWin、StaffCop、Spyrix 等 |
| **屏幕监控 / 员工监控** | Teramind、ActivTrak、Hubstaff、Time Doctor、Kickidler、Veriato、Controlio、Insightful 等 |
| **终端管控 / EDR / 杀毒** | 火绒、奇安信天擎、深信服、亚信、绿盟、安恒、启明星辰、联软、北信源、CrowdStrike、SentinelOne、Carbon Black、Symantec、McAfee/Trellix、ESET、Kaspersky、Sophos、FortiClient、Cortex XDR、SCCM、Tanium、Splunk/Elastic/Wazuh/osquery 等 |
| **抓包 / 流量监听** | Wireshark、Npcap、WinPcap、WinDivert、USBPcap、Fiddler、Charles、mitmproxy、Burp Suite、Proxyman、Reqable 等 |
| **HTTPS 中间人证书** | 受信任根证书区出现 Fiddler / Charles / Burp / Zscaler / Netskope / Fortinet / 杀软 SSL 扫描等证书 |
| **流量代理** | 系统 WinINET 代理、PAC 自动代理、WinHTTP 代理 |
| **系统行为审计** | Sysmon、Windows 事件日志转发 (WEF)、RDP 无同意影子会话、Windows Recall 已允许 |
| **可疑注入 / 钩子** | AppInit_DLLs、AppCertDlls、Winlogon 篡改、IFEO 劫持，以及**本程序自身进程被第三方 DLL 注入** |
| **远程会话** | RDP 已启用 / 正在登录、WinRM、VNC / Radmin / TeamViewer 等端口监听 |

> 系统自带的 Microsoft Defender 不列入判定，避免把系统默认防护误报成"监控"。

## v1.5.0 新增：可回滚的风险处置

检测之外，右键任意一条风险 →「解决此风险…」，程序按风险类型生成一组**可勾选的最小动作**，先预演、再执行，每一步都给出结果或明确的失败原因，全部改动留快照，可随时回滚。

- **预演**：只列出将要做的事，逐项写日志，不动系统。
- **回滚**：按最近一次处置记录倒序恢复（假象进程/服务 → 服务配置与启动类型 → 启动项/计划任务 → 证书 → 代理与注册表原值）。
- **审计**：`%LOCALAPPDATA%\EnvSentry\remedy\` 下留 `audit.log`、每次处置的 `journal-*.json`、`backup\`（证书 .cer、任务 XML、注册表文本）与 `latest.json`。
- **失败原因**：逐动作返回，例如拒绝访问（5）、服务未及时响应（1053）、驱动不能在线停止（1052）、不是安全模式不能卸载驱动（1084）、需要管理员权限——不会"整体失败但不说话"。

处置覆盖三类对象：监控类（远控 / 键鼠记录 / 屏幕监控 / EDR）、加密类（透明加密 / DLP）、策略与配置类（根证书 / 代理 / 审计 / 注入 / RDP / BitLocker）。内置 122 个厂商/产品处置手册，未收录的程序从证据里解析真实 PID、服务名、驱动名、启动项、计划任务与证书指纹后套用通用动作。

**边界（重要）**：本机处置无法伪造远端心跳——管理端仍可能看到"设备在网但无数据"；带 PPL / 反篡改 / 内核自保护的目标会返回拒绝访问，程序会明确说明并中止；加密过滤驱动无法在线卸载，已加密文件不会因此变成明文。详见 [使用说明.txt](使用说明.txt) 第十节。

> 以上能力仅用于**清理你自己的个人设备**上你不希望保留的组件。用于单位设备或规避单位管控，属于本仓库明确禁止的用途，见[使用边界](#许可与使用边界)。

## 轻量化实测

| 状态 | 工作集 | 私有内存 | CPU |
| --- | --- | --- | --- |
| 刚启动、空闲 | 17–25 MB | 52–54 MB | ~0.1% |

## 使用方法

1. 双击下载得到的 `WindowsEnvSecurityCheck.exe` → 出现「准备就绪」界面
2. 点击左下角绿色按钮 **「开始检测 (F5)」**，约 5–15 秒完成
3. 顶部横幅即结论；表格每行代表一项命中：单击看证据，双击看全文
4. 底部按钮：`[重新检测 (F5)]` `[解决风险…]` `[导出报告]` `[复制详情 (Ctrl+C)]`
5. 点右上角 `X` = **最小化到托盘**（程序不退出）；想真正退出：右键托盘图标 →「退出程序」
